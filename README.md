# Swarup Ukil

I'm studying Computer Science, with minors in Mathematics and Statistics, at the University of Toronto. I completed a year long internship working on Firefox's Gecko engine as a software engineering intern at Mozilla: my work spanned CSS parsing, layout, animation, and web platform interoperability in Rust and C++.

## Firefox contributions

- **CSS `shape()`**: parsing, interpolation, and SVG path generation, leading to its release in Firefox 148.
- **Advanced CSS `attr()`**: typed attribute values, chained substitution, cycle detection, and URL taint handling, leading to its release in Firefox 155.
- **View Transitions**: snapshot sizing, overflow clipping, animation behavior, and Android regression tests.
- **CSS `display` animations**: early implementation work toward Firefox's upcoming support, including `display` interpolation and preserving animations and transitions across conditional frame destruction.
